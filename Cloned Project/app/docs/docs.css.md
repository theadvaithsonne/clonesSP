A manual, set like one: a serif for the chapter and section titles, a
humanist sans for the text, and a mono that carries every route, event and
identifier. One superfamily (IBM Plex) so the three voices share a skeleton.

Structure is drawn with hairlines and one accent — amber, used only on the
things you navigate by. Flow diagrams are the single place a second colour
appears, because there direction is information.

Everything is namespaced under .doc-* so none of it reaches the app.
