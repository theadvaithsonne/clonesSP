# `components/bat246/GreenCardBackSvg.tsx`

> A generated React SVG component that draws the back face of the BAT 246 "Green Card" (a portrait card design), including two embedded base64 PNG images.

**Kind:** React component · **Lines:** 174 (about 673 KB on disk)

## Purpose
The BAT 246 card viewer can flip a Green Card over to show its back. This file holds that artwork as a component, so it renders inline and needs no extra image request. It is plainly the output of an SVG-to-JSX converter in the SVGR style: an anonymous `SvgComponent` arrow function, `xlinkHref` attributes, and dense path data.

## How it works
- Renders an `<svg>` with `width={1587}`, `height={2245}` and `viewBox="0 0 1190.25 1683.75"`. All passed props are spread onto the `<svg>`, so callers can override the size, class and style.
- `<defs>` holds clip paths with ids `a` through `t`, two `feColorMatrix` filters (`a`, `b`) and two masks (`n`, `t`). Mask `t` embeds a base64 PNG used as a luminance mask (line 89, about 25 KB).
- **Body:**
  - a white page, a dark-green (`#385425`) card face with a heavy black border, and a white inner panel;
  - several large vector glyph paths, filled red (`#b22f09`), white or the default black. These are the card's lettering and ornaments.
  - a large embedded base64 PNG on line 164, about 598 KB. It is masked and clipped into the top-right area and is the bulk of the file size.
- The component takes no props of its own and holds no state or logic.

## Exports
- `default SvgComponent(props: SVGProps<SVGSVGElement>)`: the card-back SVG.

## Dependencies
- **Packages:** `react` (only `SVGProps` is used; the namespace import exists for JSX).

## Used by

## Notes
- Do not edit this file by hand. Regenerate it from the source SVG instead.
- Because of its size (about 673 KB of inline data), it adds noticeably to the JS bundle of any route that imports `MiniCard.tsx`. Lazy-loading it, or serving the artwork from `public/` as a static file, would reduce bundle size.
- Clip-path, mask and filter ids are short global names (`a`, `b`, `c`, …). If another inline SVG on the same page uses the same ids, they can collide.
