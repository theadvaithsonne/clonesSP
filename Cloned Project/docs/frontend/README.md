## Environment configuration

The workspace experience supports an HQ "always on" recording mode. Control it with the following environment variable in your `.env` file:

```
NEXT_PUBLIC_HQ_FORCE_RECORDING=true
```

- When omitted or set to `true`, recording starts automatically for GARAGE HQ sessions and the in-product toggle is disabled.
- Set the variable to `false`, `0`, or `off` to keep the manual recording control available.
You can also override the HQ name that this policy applies to by defining `NEXT_PUBLIC_HQ_NAME`.
